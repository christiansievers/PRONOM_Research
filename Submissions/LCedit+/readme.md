# New file format : LCedit+ or LCeditPlus

Extension(s):
lcp

MIME/Media Types:
Unsure

Description:
LCedit+ is a computer program for editing the light cues, sequences and shows inside a LanBox lighting controller. The program has several types of windows: Stage (that holds the fixtures and light groups), Cast (lists all used fixtures and groups as a list), Control (for light-, and layer- sequencer control, setting layer and chaser parameters), Cuelist editor (for creating & editing of cues, including paths and patterns), and Monitor (to monitor various in/out values). Besides being a light editing program LCedit+ can be used to trigger light scenes and queues during performances.
